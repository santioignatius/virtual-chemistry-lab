# 🧪 Virtual Chemistry Lab - Beta

> **Conceived as Science Exhibition Exhibit & Synthesized by 9th Graders**

An interactive, single-file web application designed to make foundational chemistry intuitive, visual, and fun for middle and high school students. Built for science fairs, classroom learning, and interactive STEM exhibits.

---

## 🌟 Key Features

### 1. ⚛️ Atom Craft (Bohr Model Builder)
- **Subatomic Particle Controls:** Add or remove Protons ($p^+$), Neutrons ($n^0$), and Electrons ($e^-$).
- **Dynamic Energy Shells:** Orbiting electrons dynamically fill **K (2)**, **L (8)**, and **M (18)** shells.
- **Real-Time Property HUD:** Automatically calculates Atomic Number ($Z$), Mass Number ($A$), Net Electrical Charge, and Shell Distribution.
- **Nuclear Stability Check:** Evaluates isotope balance and electronic neutrality with constructive feedback and fun facts for stable isotopes.

### 2. 🧪 Molecule Craft (Reaction Synthesizer)
- **Distillation Reaction Chamber:** Virtual flask supporting click-to-add and drag-and-drop mechanics.
- **Element Palette Manager:** Select up to 10 active elements from the full Periodic Table palette for customized experimentation.
- **Dynamic Reactions:** Synthesize common molecules like Water ($H_2O$), Table Salt ($NaCl$), Carbon Dioxide ($CO_2$), Ammonia ($NH_3$), Hydrogen Peroxide ($H_2O_2$), and more!
- **Reaction Visuals:** Dynamic gas vapors, liquid height animation, and stoichiometric verification.

### 3. 🏆 Discovered Badges Showcase
- Earn interactive badges for each unique atom and compound successfully built or synthesized.

## 🚀 How to Run Locally

Since the application is consolidated into a single self-contained HTML file:

1. Clone or download `index.html` from this repository.
2. Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Apple Safari).
3. **No server, backend installation, or node dependencies required!**
